📊 Sales Data Calculator

📌 Project Overview

Sales Data Calculator is a simple Python-based project developed to perform basic sales data analysis.

The project analyzes a collection of sales values and calculates the total sales, average sales, highest sale, and lowest sale. It also displays the number of sales records and provides a brief explanation of the results.

This project demonstrates how Python's built-in functions can be used to perform numerical calculations efficiently.

🎯 Objectives

- To understand basic numerical data analysis using Python.
- To store and manage sales values using Python lists.
- To calculate total and average sales.
- To identify the highest and lowest sales values.
- To count the number of sales records.
- To interpret and display the analysis results.

🛠️ Technologies Used

- Python 3
- Google Colab

The project uses a manually created dataset containing seven sample sales values.

⚙️ Key Features

- Stores sales values in a Python list.
- Calculates total sales using `sum()`.
- Counts sales records using `len()`.
- Calculates average sales using arithmetic operations.
- Identifies the highest sale using `max()`.
- Identifies the lowest sale using `min()`.
- Displays the calculated statistics.
- Provides a short explanation of the results.

🔍 Methodology

1. Create a list containing the sales values.
2. Calculate the total of all sales.
3. Determine the number of sales records.
4. Calculate the average sales value.
5. Identify the highest and lowest sales.
6. Display the results in a readable format.
7. Provide a brief interpretation of the analysis.
